Последние 4 года работала главным аналитиком в компании, специализирующейся на розничной торговле. Но в какой-то момент перестала ощущать развитие, поэтому решила освоить новую профессию, чтобы открыть новые возможности! :smile:
С мая 2024 г. по январь 2025 г. проходила онлайн-обучение по основам HTML, CSS и JavaScript. 
Коммерческого опыта работы в этой сфере у меня пока нет, но есть огромное желание развиваться и я готова показать это на практике. На данный момент я сосредоточена на построении крепкой базы в веб-разработке, продолжаю изучение JavaScript и работаю над повышением уровнем английского языка до Intermediate.

Примеры моих проектов:
- Использование **стандартных CSS-методов** для адаптивной верстки https://github.com/julia8978/responsive-hotel-page
- Использование навыков адаптивной верстки с использованием технологии **Flexbox** https://github.com/julia8978/travel-moodboard
- Использование методологии **БЭМ** и применение **SCSS** https://github.com/julia8978/restaurant
- Использование **JavaScript** для создания интерактивного одностраничного сайта: https://github.com/julia8978/my-exotic-fruits-store
- Использование **JavaScript** для создания веб-приложения для изучения английских слов: https://julia8978.github.io/foreign-words-training/
